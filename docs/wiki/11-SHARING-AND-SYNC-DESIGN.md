# 11. 会话分享、共享与朋友间同步设计（参考 Immich）

> **状态更新**：本文档的分享令牌、导入语义与会话集（Album）机制已于 Phase 3 实现并验证，实现细节见 [12-AUTH-SHARING-IMPLEMENTATION.md](./12-AUTH-SHARING-IMPLEMENTATION.md)。本文保留产品设计与 Immich 映射决策。

## 1. 目标

在个人多设备同步之外，新增“朋友之间共享会话资产”的能力：把部分会话分享给指定朋友，对方一键导入到自己的云端 Hub，再同步到本地 Agent。整体模型参考 Immich 相册的分享体系，但按会话资产的特性做取舍。

## 2. Immich 的可借鉴逻辑

| Immich 机制 | 映射到 Agent Sync Hub |
| :--- | :--- |
| 相册 (Album) | 会话集 (Session Collection)：按项目或主题打包一组会话 |
| 分享链接 + 有效期 + 密码 | 分享令牌 (Share Token)：短 ID + 过期时间 + 可选访问码 |
| 只读分享 / 可上传协作者 | 只读分享 / 可导入分享（本期只做只读） |
| 合作相册 (Partner Sharing) | 后续：好友关系 + 双向授权（暂不做） |
| 原始文件 + 缩略图分离 | 会话正文（JSONL）+ 摘要索引（标题/项目/消息数）分离 |
| 存储配额 | 接收配额：限制单用户可导入总量（后续） |

不建议照搬的部分：Immich 的“多用户共用一个服务器、共享原始照片库”模式。会话内容可能包含代码、密钥片段和商业信息，默认模型应是“分享是主动的、最小化的、可撤销的”，而不是“服务器成员互相可见”。

## 3. 推荐产品形态

### 3.1 分享方（你）

1. 在统一会话资产库勾选若干会话（跨项目允许）；
2. 点击“生成分享链接”，弹出配置：
   - 有效期：24 小时 / 7 天 / 永久（可撤销）；
   - 访问码（可选，4-8 位）；
   - 允许的操作：仅查看 / 查看并导入；
3. 系统生成 `https://<host>/s/<shortId>?code=****`，发给朋友；
4. 分享页只有会话摘要 + 只读预览 + “导入到我的 Hub”按钮。

### 3.2 接收方（朋友）

1. 打开分享链接，看到只读预览；
2. 点击“导入到我的 Hub”时填写自己的 Hub 地址（自部署模式）或登录自己的账号（托管模式）；
3. 导入后，会话进入其云端 Hub，标记来源为 `shared-in`，与本地库合并展示；
4. 之后走现有流程：选择目标 Agent + 目标项目路径 → 注入本地。

## 4. 数据模型（最小实现）

```json
// share.json（云端 Hub 存储，随会话 JSON 一起放）
{
  "shareId": "aB3xK9",
  "createdAt": 1791900000000,
  "expiresAt": 1792504800000,
  "accessCodeHash": "sha256(...)",
  "allowImport": true,
  "sessionIds": ["01a...", "01b..."],
  "createdByDevice": "dev-win-01",
  "revoked": false
}
```

导入的会话在 Canonical JSON 中追加元数据：

```json
"metadata": {
  "shareOrigin": { "shareId": "aB3xK9", "importedAt": 1791900300000, "originalAgent": "codex" }
}
```

## 5. API 设计（增量）

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| POST | `/api/shares` | 勾选会话创建分享，返回链接 |
| GET | `/s/:shareId` | 分享落地页（校验过期/访问码） |
| GET | `/api/shares/:shareId/sessions` | 分享内容摘要列表 |
| GET | `/api/shares/:shareId/sessions/:id` | 单会话完整 Canonical JSON（只读） |
| POST | `/api/shares/:shareId/import` | 接收方拉取会话到自己 Hub（服务端转发抓取） |
| DELETE | `/api/shares/:shareId` | 撤销分享 |

## 6. 安全边界（必须遵守）

1. 分享是按会话粒度的显式行为，不做“整个云端库共享”；
2. 上传前强制 Cleaner 脱敏 + 用户可预览正文；
3. 访问码哈希存储；分享链接含短 ID（≥6 位随机，防枚举）；
4. 默认过期时间 7 天；撤销立即生效；
5. 公网暴露 Hub 前必须加登录（哪怕简单的账号密码 + HTTPS），否则分享接口等于向全网开放写入口；
6. 导入是复制语义：接收方拿到副本，原会话不受影响，双方后续修改互不同步（本期明确不支持“双向同步好友会话”）。

## 7. 与 Immich 的差异决策记录

1. 不做服务器级多用户注册体系（一期）：你的 Hub 是“个人云 + 邀请分享”，不是 Immich 那种“家庭共享服务器”；
2. 不做实时同步共享集：分享是快照导入，避免朋友的 Agent 在错误路径上执行命令的连锁风险；
3. 不做评论/点赞等社交功能：会话资产的核心动作是“导入并继续干活”。
